## Files

- `data/choice.experiment1.rds`: Experiment 1 test-trial choices (32 participants, 512 trials)
- `data/choice.experiment2.rds`: Experiment 2 test-trial choices (44 participants, 1,056 trials)
- `materials/ConfederatesScriptManipulationItems.pdf`: Experiment 2 script, manipulation items
- `materials/ConfederateScriptTestItems.pdf`: Experiment 2 script, test items
- `analyses/AdapPragmaticMultiparty_exp1.html`: authors' Experiment 1 analysis notebook
- `analyses/AdaptPragmaticMultiparty_exp2.html`: authors' Experiment 2 analysis notebook
