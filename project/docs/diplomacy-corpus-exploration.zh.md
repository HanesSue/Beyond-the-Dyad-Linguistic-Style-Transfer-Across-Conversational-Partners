# Diplomacy 语料初步考察

2026-11-07 · 对应代码：[describe_corpus.py](../src/describe_corpus.py)、[pilot_carryover.py](../src/pilot_carryover.py)

这份笔记检查 [Diplomacy 语料](../../datasets/diplomacy/README.md)能否支撑[文献综述](../../proposal/beyond-the-dyad-literature-review.zh.md)第四节的设计：预测 P 对 B 的产出时，在 P 本人基线和 B 的输入之外，其他伙伴 A 的输入是否提供额外信息。**结论：语料结构适合这个问题。先导分析中，同伴输入的效应清楚，第三方输入暂未见效应，但目前两者的比较并不对等，不能据此下结论。**

## 一、语料概况

- **规模。** 12 局，每局 7 国，共 17,289 条消息。各局 427 至 3,302 条不等。官方切分为训练 9 局、验证 1 局、测试 2 局。
- **单位。** 每行是一局中一对玩家的全部对话。每局 21 对组合都有记录，其中 6 对没有任何消息。第 6 局的意大利只收不发。
- **时间。** 没有真实时间戳。`absolute_message_index` 在每局内是从 0 开始、无缺号、无重复的全序，可以重建整局所有消息的先后。另有游戏内的年份（1901–1910）和季节。
- **玩家身份。** 只能用「局号 + 国家」识别，跨局无法对应到同一真人。个人基线只能在局内建立，局初存在冷启动问题。
- **分数字段。** `game_score` 是发信人当季的补给中心数，`game_score_delta` 是发信人减收信人的分差。两条规则在可核对的 16,958 条消息上全部成立。
- **欺骗标注。** 发信人自报说谎占 5.1%（887 条）。收信人判断有 1,506 条为 `NOANNOTATION`，约占 9%。
- **数据质量。** 平行数组长度一致，没有自己发给自己的消息，同局内的组合没有重复。同一发信人、收信人与文本完全相同的消息有 74 条，几乎都是 👍、ok、Rgr、Lol 这类短回应，属于正常现象。
- **消息长度。** 中位数 14 个词（71 个字符）。四分之一的消息不超过 7 个词，95% 分位数是 60 个词。
- **分布不均。** 一人一局发出 14 至 945 条，中位数 130 条。一对组合的消息数中位数是 30.5，最多 675。83 个「玩家-局」中，71 个给全部 6 个对手都发过消息。

## 二、对研究设计有利的结构

**对话确实交错进行。** P 连续两条发出的消息中，42.1% 换了收信人。P 两次写给 B 之间，有 37.7% 的情况收到过其他伙伴的消息（中位数 0 条，75% 分位数 2 条，90% 分位数 9 条）。P 发消息给 B 时，最近收到的一条来自 B 的情况占 66.5%。P 第一次给 B 写信的消息只占 2.8%，98.8% 的消息发出时 P 已收到过至少两位伙伴的来信。

**语料包含整局所有人之间的全部消息。** 因此可以确定哪些消息 P 没有看到。这些消息与 P 收到的消息处在同一游戏阶段、话题相近，但 P 没有接触过，适合作**安慰剂对照**：如果「P 没看到的消息」也能预测 P 的用法，效应就更可能来自共同的局势和话题，而不是接触。

## 三、风格标记的频率

标记用正则表达式粗略识别，记录一条消息是否至少出现一次。玩家间差异按发出至少 40 条消息的 72 个「玩家-局」计算。

| 标记 | 总体出现率 | 玩家间（第 10 / 50 / 90 百分位） |
| --- | ---: | --- |
| 缩略形式 I'm / don't | 49.2% | 33.5% / 48.5% / 64.5% |
| 问号 | 24.5% | 16.1% / 24.3% / 36.7% |
| 弯引号 ’（键盘决定，作对照） | 18.4% | 0% / 0% / 47.0% |
| we / us / our / let's | 18.1% | 10.6% / 17.9% / 28.4% |
| 模糊语 maybe / perhaps / I think | 12.4% | 6.1% / 12.5% / 19.2% |
| 感叹号 | 7.5% | 0.8% / 5.3% / 17.4% |
| 表情符号 | 3.8% | 0% / 2.9% / 11.2% |
| 省略号 | 3.7% | 0% / 2.0% / 10.7% |
| 笑声 lol / haha | 3.0% | 0% / 1.5% / 5.5% |
| 全小写 | 2.7% | 0% / 1.3% / 10.9% |
| **情态请求 could / would / can / will you** | **2.5%** | 0% / 2.4% / 5.5% |

**需要遮盖的游戏内容。** 37.6% 的消息提到国家名（含 eng、fra 等缩写），4.4% 含走子指令（如 `A PAR - BUR`）。这些内容测量风格前应先遮盖。

## 四、先导分析

**做法。** 对每条 P→B 消息和每个标记，用逻辑回归预测该消息是否含有这个标记。关心的三个预测变量：

- **B_in**：B 发给 P 的最近一条消息是否含该标记（同伴）
- **O_in**：除 B 以外，任何人发给 P 的最近一条消息是否含该标记（第三方）
- **U_unseen**：两名其他玩家之间、P 没看到的最近一条消息是否含该标记（安慰剂）

控制变量包括：P 此前的使用率（向全语料率收缩，伪计数 10，取 logit）、P 上一条发出的消息、P 在对方回信之前写给对方的最后一条消息（P 的风格被反射回来的部分），以及当前消息的对数长度。标准误按「玩家-局」聚类。P 此前至少发过 3 条、且三类输入都存在的消息纳入分析，共 16,710 条。

**结果**（对数胜算，方括号为 95% 置信区间）：

| 标记 | 出现率 | B_in 同伴 | O_in 第三方 | U_unseen 安慰剂 | P 上一条 |
| --- | ---: | --- | --- | --- | --- |

出现率按纳入分析的消息计算，与第三节略有差异。

**读法。**

- **同伴输入的效应清楚。** 笑声、表情符号、感叹号和 we 类代词随 B 的上一条消息明显增加。
- **第三方输入基本为零。** 13 个标记中只有 thanks 勉强显著。在 12 个可估计的检验里出现一个，很可能是偶然。
- **安慰剂全部接近零。** 「同一时期大家说话都像」没有污染这套分析。
- **键盘对照符合预期。** 弯引号只与 P 自己的上一条消息有关（+0.69），与任何收到的消息无关。

**为什么现在还不能说「没有跨伙伴迁移」。**

1. **时间距离不对等。** 按全局顺序，B 的上一条输入中位数在 3 条消息之前，第三方的在 11 条之前。
2. **同伴效应混入了对话连贯性。** P 常常是在直接回复 B：对方开玩笑就回 lol，对方提问就作答而不是反问，问号的负效应正是这样来的。这类反应不一定是风格适应。
3. **只看了最近一条输入。** 累积暴露和近期加权都还没有建模。
4. **统计功效不均。** O_in 的置信区间在常见标记上约为 ±0.1，在出现率 2%–4% 的标记上约为 ±0.5 或更宽。

## 五、对后续分析的建议

1. **用留一局交叉验证。** 只有 12 局，固定的 9/1/2 切分中测试集只有 2 局，估计不稳。
2. **让比较对等。** 比较同伴与第三方时，让两者与 P 当前消息的时间距离相近，并把直接回复 B 的消息单独处理或作为调节变量。暴露量用时间窗口内的累积量，再比较等权与近期加权（对应文献综述的 Xu 与 Futrell、Reitter 等）。
3. **把「P 没看到的消息」设为标准对照。** 每项分析都同时报告安慰剂。
4. **把键盘决定的标记作为负对照。** 弯引号这类标记不计入风格指标。
5. **合并或分层处理稀有标记。** 把稀有标记合并到更大的类别，或用跨标记的层级模型（如 Doyle 与 Frank 的 WHAM）共享信息。
6. **先遮盖游戏内容。** 国家名、地名和走子指令都要遮盖，再测量风格。
7. **控制长度和话语功能。** 消息普遍很短，长度必须进入模型。欺骗标注和问句、请求等言语行为可以作为话语功能条件。
