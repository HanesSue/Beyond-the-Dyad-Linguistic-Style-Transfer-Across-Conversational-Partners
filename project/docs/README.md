## 研究问题

一个人（P）从伙伴 A 那里接触到某种表达风格后，对另一位伙伴 B 说话时会不会也带上这种风格。做法是在 Diplomacy 语料（Peskov 等，2020；12 局、17,289 条消息）上，把每条 P → B 消息当成一次预测试次，把消息表示为多维风格向量，比较四个模型对下一条消息风格的预测。

| 模型 | 读取的经验 |
| --- | --- |
| 基线 | 仅 P 的个人基线和可见语境 |
| 伙伴特异 | 每位伙伴独立更新 |
| 完全汇聚 | 所有来源合成一个共享预期 |
| 层级（部分汇聚） | 共享预期与伙伴特异预期并存 |

### E. 实证工作（暂缓）

方案定稿后按以下顺序进行：风格测量的实现与验证 → 四模型的顺序回放 → 受控模拟 → 真实数据比较 → 近期加权等扩展。模拟不依赖真实数据的测量质量，可以最先做；即使真实数据上的效应不清楚，模拟部分也能独立构成一份完整的建模结果。

## 建议优先讨论

1. **B1 候选维度清单。** 测量、模型和评估都以它为输入，最先定。
2. **C4 同伴与第三方的对等比较。** 这是先导分析暴露出的最大问题：同伴输入的效应可能混入了时间距离和直接回复。
3. **B4 测量验证标准。** 决定了“风格向量测到了风格”这一主张能否成立。
4. **D1–D3 模拟设计。** 能提前说明在这份语料的样本量下，哪些模型差别是检测得到的。

## 已有的探索性证据

先导回归（01 第 11 节）显示，B 的上一条消息清楚地预测 P 对笑声、表情、感叹号和 we 类代词的使用；第三方输入的效应接近零，安慰剂和键盘负对照也都接近零。但第三方输入在时间上更远，同伴效应里混有直接回复，且只看了最近一条输入，因此还不能说明“没有跨伙伴迁移”。这一结果主要用来指导 C4 和 D3 的设计。
