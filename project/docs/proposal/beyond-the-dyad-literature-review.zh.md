# Beyond the Dyad: Linguistic Style Transfer Across Conversational Partners

**超越双人对话：语言风格的跨伙伴迁移**

## 文献综述

人在与他人交流时，会根据先前接触的语言调整自己的理解或表达。当这种调整出现在原来的交流伙伴之外，一个重要的认知问题是：**学习者把局部经验归入了共同的交流规律，还是先前接触的表达在眼下更容易被调用？** 这两种机制都可能使人对不同伙伴说得更像，但对换人、暴露顺序和经历累积的预测不同。

本项目把问题落到**同一个人的后续语言产出**。当 A 经常采用某种表达形式后，P 面对 A 和 B 时使用该形式的概率是否改变？以下研究分别提供人类行为对照、候选认知机制，以及从自然对话中测量风格的方法。

## 一、人类行为证据：适应发生在伙伴层面还是情境层面？

### 1. Kronmüller 与 Guerra（2026）｜说话人的命名习惯会改变听者的推断吗？

- **研究意义。** 当一件物体已经有称呼，说话人又用了一个能同时描述它和另一件物体的新表达，听者往往推断新表达指向此前未被命名的物体。这叫**互斥推断**（mutual exclusivity inference, MEI）。研究追问，当某位说话人会给同一物体换称呼时，听者会只对他降低这种推断，还是在整个交流情境中都变得更谨慎？
- **实验设计。** 实验一用预录语音呈现两位说话人，比较两人都保持指称一致的情境与其中一人有时更换称呼的情境。实验二改为面对面互动，先建立两人都一致的基线，再引入其中一人的不一致行为。两项实验都记录选物和眼动。实验二另用问卷检查参与者是否意识到了两人的差异。
- **模型架构。** 文章采用的是**行为实验加统计分析**。输入为暴露条件、说话人身份及试次结果，混合效应逻辑回归估计选择未命名物体的概率怎样随条件变化，眼动分析检查变化何时出现。暴露阶段提供可供听者学习的证据，统计模型检验其行为后果。
- **研究结论。** 两项实验均未检出可靠的说话人特异调整。实验一中，只要情境中有一位说话人的命名不一致，听者面对两位说话人时都较少选择未命名物体。实验二没有复现这个情境效应，尽管问卷显示参与者能意识到说话人之间的差异。[Kronmüller 与 Guerra 原文](https://www.cambridge.org/core/journals/language-and-cognition/article/adapting-pragmatic-interpretation-in-multiparty-conversations-mutual-exclusivity-inferences-across-speaker-and-context/1E1F61CEF8330564366F54ECCC66825E)

这篇文章提供了本项目的问题起点。它把**知道谁有某种习惯**和**在当前行为中使用这份知识**分开。我们的因变量改为自己的表达，所以需要用产出数据重新检验这一区分。

### 2. Ostrand 与 Ferreira（2019）｜说话者会按当前伙伴的句式偏好调整吗？

- **研究意义。** 双宾语和介词与格可以描述同一个给予事件，例如 *The chef gave the waiter a book* 和 *The chef gave a book to the waiter*。当两种形式都能顺畅传递信息时，人是否仍会特意匹配当前伙伴惯用的结构？
- **实验设计。** 五项实验让参与者先听两位实验者描述图片，再分别向他们描述新图片。实验四最适合作对照。在**相反偏好条件**下，A 只用一种句式，B 只用另一种。在**混合条件**下，两人都使用两种句式。两个条件的总体输入相同，各包含 24 次双宾语与 24 次介词与格，差异在于这些句式如何分配给 A 和 B。
- **模型架构。** 输入是暴露条件、当前听者及参与者的句式编码。广义线性混合模型估计**介词与格的产出概率**，检查暴露条件与当前听者是否有交互。这个交互对应一个具体预测：若人按伙伴适应，相反偏好条件中的 A、B 产出应出现方向明确的差异。
- **研究结论。** 实验四中，整体输入偏向介词与格时，参与者比在整体偏向双宾语时更多采用介词与格。在总量相同的相反偏好与混合条件中，没有发现可靠的伙伴特异匹配。参与者也能把实验者讲过的个人事实归给正确的人。事实归属表现与是否记得对方的句式偏好是两项测量。[Ostrand 与 Ferreira 原文，实验四](https://rostrand.github.io/papers/Ostrand_Ferreira.2019-JML.pdf)

这项研究最接近本项目的**产出端**。它也给出一个值得保留的设计原则：**把总体暴露量与暴露来源分开。** 我们已经核查过的实验四公开产出资料，可作为受控人类基准。Diplomacy 则可以探索这一模式是否也出现在自然、策略性的交流中。[公开数据](https://osf.io/tafnb/)

## 二、三种认知机制：经验如何进入下一次表达？

### 3. Xu 与 Futrell（2024）｜层级贝叶斯学习怎样产生句式迁移？

- **研究意义。** 刚经历过一种句式后，换动词仍可能复用结构，但沿用同一动词时通常影响更强。作者问，这两种现象是否都能由**局部经验与共享句式知识之间的联系**解释。
- **实验设计。** 研究以既有人类补句实验为参照进行两项模拟。第一项比较前句采用双宾语还是介词结构，以及前后动词是否相同。第二项向暴露组和对照组加入后续语言经历，观察原有启动差距是否缩小。背景经验按语料频率构造，共有九个动词的 100 条记录。
- **模型架构。** 输入是编码后的「动词＋句式」记录，例如 `give + 双宾语`。模型维护**所有动词的共同句式偏好** $\Theta$ 和**每个动词的特定偏好** $\phi_v$。见到 `give` 使用双宾语会直接更新对 `give` 的信念，也可能推高共同倾向，再间接影响对 `show` 等动词的预测。输出是待测动词采用双宾语或介词结构的后验预测概率。MCMC 用来近似计算这些后验。
- **研究结论。** 模型定性重现了三个模式：同动词的启动更强，先验下较出乎预期的结构带来较大变化，加入后续经历时同动词的额外影响衰减更快。这里的衰减来自**继续接触语言带来的干扰**。模型仍保留同动词优势，未重现一些实验中该优势完全消失的情况。[Xu 与 Futrell 原文，Figures 2–3](https://arxiv.org/html/2405.15964v1)

它给本项目提供了一个**从编码经历到表达概率**的最小范例。迁移到我们的任务时，可以用同样的思路区分局部与共享统计，同时把「当前面对谁」明确写进产出规则。跨动词泛化与跨伙伴泛化是两个需要分别验证的现象。

### 4. Hawkins 等（2023）｜CHAI 怎样同时解释伙伴特异与群体泛化？

- **研究意义。** 两个人反复交流后，可能用一个很短的称呼就能指对物体。换人后，这个简称未必管用。但若很多伙伴都理解同一简称，人又可能对陌生人直接使用它。作者试图用一个模型解释**局部约定如何形成，以及何时值得推广**。
- **实验设计。** 论文以模拟考察表达简化，并配合两项人类实验。与本项目最相关的是四人网络实验：92 位参与者组成 23 组，每人轮流与其余三人完成图形指称游戏。每轮一人描述目标图，另一人选择，随后双方得到目标与选择反馈。另一项实验改变同屏物体需要区分的细致程度，考察交流环境怎样改变词义范围。
- **模型架构。** CHAI 将**层级贝叶斯学习**与 **RSA 语用决策**结合。输入包括伙伴、当前物体集合、候选表达和过去的反馈。每个代理维护各伙伴的**词义系统**以及自己的**群体预期**。一轮结束后，能更好解释对方刚才行为的词义系统获得更高后验概率。说者根据这些信念权衡表达的可理解性与表达成本，输出各种候选表达的概率。听者则输出选择各物体的概率。面对新伙伴时，代理从更新后的群体分布出发。
- **研究结论。** 人类数据表现出同伙伴内描述缩短、换人后回升、面对后续伙伴时起始描述逐渐缩短。**部分汇聚**模型能同时预测这些变化：经历较少时保留对原伙伴的谨慎区分，多个伙伴提供一致证据后再加强群体推广。论文以行为模式和参数范围下的模型比较为主。[Hawkins 等原文，Figure 7 与 Inference Details](https://cocosci.princeton.edu/papers/hawkinspartners.pdf)

**CHAI 和 Ostrand 与 Ferreira 的结果可以放在一起理解。** 在 CHAI 中，伙伴知不知道某个简称会影响他能否选对图。在句式实验中，两种结构通常都足以传达同一事件。两项任务给伙伴信息提供了不同程度的用途。对于 Diplomacy，是否按对象调整表达可能与请求、说服或协调有关。因此，话语功能应成为分析条件，伙伴特异性与跨伙伴迁移也可以同时存在。

### 5. Reitter、Keller 与 Moore（2011）｜记忆可及性怎样产生句式复用？

- **研究意义。** 人重复一种结构，可能是因为它现在更容易从记忆中取出。研究把这一想法具体化，解释频繁使用、最近使用和词语重叠如何影响句式选择。
- **实验设计。** 作者用多项模拟改变结构频率、前后间隔、累积暴露及词语重叠。部分模拟先让模型用一种指定结构表达某个意义，再给它另一个事件，让它自由选择句式。作者还用 Switchboard 真实电话对话检验模型关于词汇重叠的预测。
- **模型架构。** ACT-R 将词汇与句法信息表示为可提取的**记忆块**。输入是待表达的意义、词汇线索和以往使用记录。**基础激活**取决于某个记忆块过去出现的次数和新近程度。**扩散激活**来自当前词语等线索与句法结构之间的关联。两部分共同改变结构被提取的可能性，进而影响模型逐步生成的句子和最终采用的结构。
- **研究结论。** 模型可以产生短时启动、长期累积适应及词汇重叠增强等模式。语料分析支持一个较具体的预测：结构复用的短时增强与更广泛的词汇重叠有关，作用不限于重复句法中心词。[Reitter、Keller 与 Moore 原文，§4](https://homepages.inf.ed.ac.uk/keller/papers/cogsci_journal11.pdf)

它与 Xu、Futrell 的模型提供了一个实质性的对比。**后续输入不断更新统计，可以让旧影响变弱。旧经历变得较难提取，也可以让影响变弱。** 因此，仅观察到近期输入较强，无法区分这两条路径。Diplomacy 可以比较暴露次数相近、消息间距不同的历史。若要进一步判断真实时间衰减或检索成本，还需要对应的时间和加工测量。

## 三、自然对话怎么测？把词语重合、表达结构和话语功能分开

### 6. Doyle 与 Frank（2016）｜词语复用和抽象类别对齐是同一回事吗？

- **研究意义。** A 用了 *maybe*，P 也用 *maybe*，这可能只是同一个词被复用。如果 P 改用 *perhaps*，才更接近「不确定表达」这个类别的对齐。把两者混在一个相似度里，会使我们误判变化的层次。
- **实验设计。** 作者分析 Switchboard 电话和 Twitter 回复，分别估计原词复用、类别对齐，以及排除原词后同类别其他词的使用变化。作者还用模拟检查消息长度的影响，并在电话语料中考察去除简短反馈语后，结果会如何改变。
- **模型架构。** **Word-Based Hierarchical Alignment Model（WHAM）** 输入前句是否出现某个标记、回复中该标记的次数及回复总词数。模型在类别、标记和对话双方等层级估计基线及对齐量。输出是前句有该标记时，回复采用该标记的对数胜算相对基线的变化。
- **研究结论。** 两份语料中的对齐主要发生在词汇层面，排除原词后对抽象类别对齐的证据较有限。简短反馈语等话语行为还会改变估计出的效应。[Doyle 与 Frank 原文](https://aclanthology.org/P16-1050/)

这篇文章为 Diplomacy 提供了最直接的分析参照。我们可以分别报告**复用了同一个词**和**换了词但采用相同结构**，并在同类言语行为中比较。每个指标要有相应分母，例如情态疑问句应在可以辨识的请求中计算使用率。

### 7. Halvani 与 Graner（2021）｜POSNoise 怎样减少主题词的影响？

- **研究意义。** 两段文字可能因为都谈同一个主题而相似。作者提出一种可检查的预处理方法，把一部分内容信息从文本表征中减弱，同时保留语法形式。
- **实验设计。** 在多套作者验证语料上，将原始文本、POSNoise 处理后的文本及另一种内容遮盖方法进行比较。研究还检查处理之后文本能在多大程度上被用于识别主题。
- **模型架构。** 输入是原始文本及词性标注。规则保留选定的功能词、短语、缩写等表达线索，将不少承载内容的词换成对应的词性标记。输出是保留部分句法轮廓的文本，可以继续抽取短语模式或交给下游分类器。遮盖规则承担的是**测量工作**，研究者另行训练或拟合下游方法。
- **研究结论。** 多数测试组合中，POSNoise 在作者验证任务上优于研究使用的对照遮盖方法。主题测试也表明，一些被保留的语言形式仍携带主题信息。[Halvani 与 Graner 原文](https://arxiv.org/abs/2005.06605)

对本项目，可以先遮盖国家名、地名、玩家名和行动代码，再保留情态词、代词、缩写与句型。这样做后，仍应检验主题和话语功能在多大程度上影响指标。

### 8. Wegmann、Schraagen 与 Nguyen（2022）｜如何检查向量更像是在量风格还是内容？

- **研究意义。** 即使一个向量能区分作者，它也可能利用作者偏爱的题材。论文把「能认出谁写的」和「能识别怎样写的」拆成不同的检验。
- **实验设计。** 作者在训练中使用会话或领域信息控制内容，并在 **STEL-Or-Content** 测试中让模型作选择。一条候选句与原句内容相近、风格不同，另一条内容不同、风格相近。这个设计让两种相似性直接竞争。
- **模型架构。** 输入是文本及训练时构造的作者、会话关系。对比学习调整文本编码器，使同作者跨会话的文本更接近，并借助同会话的不同作者例子减少依赖共同话题。输出是文本风格向量，可以据此计算距离。
- **研究结论。** 在会话层面控制内容的模型比普通文本编码器更能捕捉风格。最难的风格与内容竞争测试仍然表现有限，说明即使使用专门训练的向量，内容仍可能主导某些判断。[Wegmann 等原文，§4.3](https://aclanthology.org/2022.repl4nlp-1.26/)

对本项目，最值得直接复用的是**验证方法**。用同一个请求的两种说法检验指标能否感受到形式变化，再用相同句式、不同请求内容检验它对内容变化是否相对稳定。这套检验也适用于可解释的特征向量，允许我们同时探索情态句式、缩写、代词和标点，无须事先押注哪一个维度会出现迁移。

## 四、这些研究怎样共同约束我们的模型？

| 我们要区分的解释 | 文献提供的依据 | 在 Diplomacy 中的可检验比较 |
|---|---|---|
| **本人习惯与伙伴输入** | Reitter 等区分既有使用历史与近期线索。Doyle 与 Frank 用基线频率衡量对齐。 | 先用 P 自己的旧表达和语境预测，再加入来自伙伴的输入，看预测是否改善。 |
| **当前伙伴影响与跨伙伴迁移** | Ostrand 与 Ferreira 固定总体输入、改变来源分布。CHAI 比较共享与分伙伴学习。 | 预测 P 对 B 的产出时，先加入 B 给 P 的历史，再检查 A 等其他伙伴的输入是否提供额外预测信息。 |
| **等权累积与近期加权** | Xu 与 Futrell 展示后续输入可冲淡早期经验。Reitter 等给出记忆提取的近期性机制。 | 在来源结构一致的模型里，比较所有经历等权与较早经历折扣。模拟中固定暴露总量，改变其出现位置。 |
| **共同话题与表达方式变化** | Doyle 与 Frank 区分词与类别。POSNoise 和 Wegmann 等提供遮盖和对照方法。 | 将词汇复用与抽象形式分开，验证指标，并在同类言语行为与相近游戏阶段比较。 |

以情态疑问句为例，假设 A 常用 *Could you …?* 提请求。若 P 后来也在对 B 的请求中更常使用这一句型，我们首先检查 P 本来的请求方式、B 先前怎么说，以及两个时段的请求是否可比。若 A 的历史在这些条件之外仍能提高对留出游戏的预测，结果支持模型纳入**跨伙伴输入**。若进一步发现，同样数量的 A 式输入集中在最近时预测更准，结果支持在这个模型中加入**近期性**。两项检验分别回答经验**从哪里来**和**怎样随间隔发挥作用**。

Diplomacy 提供真实玩家的发信人、收信人、文本和游戏内顺序，可以重建上述历史。语料来自策略性谈判，接触经历与伙伴选择会随局势变化。因此，本项目的经验结论应限定为：**在可观察语境和本人基线之外，哪种学习与产出规则能更好预测真实人类的后续表达。** 受控模拟可进一步显示各机制在同样输入下会产生什么差异。至于参与者是否明确知道伙伴的风格，以及复用是否源于更低的检索成本，则分别需要独立的伙伴知识测量和加工证据。[Diplomacy 数据论文](https://aclanthology.org/2020.acl-main.353/) · [语料字段说明](https://convokit.cornell.edu/documentation/diplomacy.html)

项目使用的公开语料见 [Diplomacy 数据与来源说明](../datasets/diplomacy/README.md)。
